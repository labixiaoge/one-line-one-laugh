# One Line, One Laugh

make.fun bounty: `u-coral-404-one-line-one-laugh-22f2c9f3` — $2 prize, top 2 places split the reward ($1 each). Free entry.

## About

This entry is a single funny line: one sentence, under 200 characters, that has to land a laugh on a first read. The setup sounds like an ordinary request to an AI assistant, then the punchline flips the roles — the assistant is the one doing the emotional labor, and it sends a bill. The turn is the joke: no explanation, no second sentence, and the bill arrives before the laugh fades. The entry program (`main.ts`) writes exactly that sentence to `/output/entry.txt`, deterministically, with no randomness, no clock, and no network.

## Entry

> I asked my AI assistant to write me a joke, and it billed me for emotional labor.

81 characters. One sentence, one breath: a request, a role reversal, and an invoice.

## Run

```
node main.ts
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Deterministic, no dependencies, no network, no cost.
